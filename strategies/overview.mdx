## Additional planned integrations

Enosys, SparkDEX, Spectra, Gamma, Gearbox, rewards / harvest modules, and future approved DeFi venues. See [Additional integrations](/strategies/additional-integrations).

## Rule

An integration is not `SUPPORTED` merely because a protocol is EVM-compatible. Every strategy integration must verify: canonical interfaces, deployed contract addresses per chain, oracle configuration, emergency-exit path, and liquid-vs-nominal liquidity calculation. See the [Capability matrix](/reference/capability-matrix).
