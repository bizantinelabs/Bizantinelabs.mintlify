Status labels used throughout this documentation:

| Label | Meaning |
| --- | --- |
| `LIVE` | Deployed, roles verified on chain, production-enabled |
| `PILOT` | Deployed, small caps, heightened watch |
| `TESTNET` | Deployed to a testnet only |
| `READ-ONLY` | Level-1: state read and reconciled, no write |
| `SHADOW MODE` | Level-2: transaction built and simulated, never submitted |
| `IN DEVELOPMENT` | Code being written |
| `PLANNED` | Not yet started |
| `REQUIRES PLATFORM APPROVAL` | Blocked on external role, whitelist, or contract assignment |
| `NOT VERIFIED` | Address or role holder has not been read from chain |
| `DEPRECATED` | Removed or superseded |
