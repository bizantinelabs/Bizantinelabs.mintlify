## Level model

| Level | Meaning |
| --- | --- |
| **Level 1** | Read / reconcile |
| **Level 2** | Build \+ simulate (never auto-submit) |
| **Level 3** | Execute |

See [Deployment status](/introduction/deployment-status) for the current Level of each platform.

## Rule

No connector is marked write-capable, and no role is asserted Bizantine-controlled, until the deployed contract and role assignment are read from chain. Missing address ⇒ connector ships read-only/scaffold with the exact blocker stated. `UNKNOWN` ⇒ `BLOCKED`.
