Every operational action passes:

1. [Permission engine](/architecture/permission-engine) — must return `EXECUTABLE`
2. Transaction build against the platform connector
3. Simulation — must succeed
4. Route to signer (Safe / Fordefi)
5. Execute
6. Reconcile

No step is skipped, ever.
